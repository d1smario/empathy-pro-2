1. Cosa misuriamo

Empathy è una piattaforma multilayer (ingest → motori → twin → interpretazione → applicazione) con moduli prodotto, motori numerici proprietari, integrazioni device multi-vendor, AI interpretativa (non sostitutiva dei motori), schema Supabase con memoria atleta canonica e documentazione architetturale estesa.

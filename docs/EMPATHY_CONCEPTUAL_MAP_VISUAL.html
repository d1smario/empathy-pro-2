I quattro piani (flusso end-to-end)

Piano 1
Ingest
Device, lab, profilo, diario, import — dati normalizzati e qualità.
→
Piano 2
Compute
Motori, twin, solver nutrizione, builder sessione — verità numerica.
→
Piano 3
Interpretation
Pathway, knowledge, trace — non sovrascrive i numeri motori.
→
Piano 4
Application
Moduli, API thin, export, coach — azioni e presentazione.

Stessi strati, due nomi (L4–L1 ↔ piani)

Allineamento

L4 Data ≡ Ingest + storage
L3 Motori ≡ Compute (twin, fisiologia)
L2 AI / interp. ≡ Interpretation
L1 App ≡ Application

Invarianti (da constitution)

Reality > Plan · Physiology > UI · carico interno > esterno dove definito.

Un solo builder canonico per la singola sessione; calendario operativo; VIRYA periodizza e materializza verso il builder; l’AI non sostituisce i motori sui numeri canonici.
